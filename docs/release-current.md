# Release Notes — Novità

- Sincronizzazione cifrata più leggera: se nel cloud non è cambiato nulla l'app non riscarica il salvataggio, e un'impostazione cambiata su un altro dispositivo non viene più riportata indietro.
- Dati cifrati più rapidi da aprire e salvare sulla TV, e i controlli del profilo bambino rallentano da soli quando il server non risponde invece di riprovare di continuo.
- Il salvataggio cifrato nel cloud ora è compresso e pesa molte volte meno: aggiorna l'app su ogni dispositivo, le versioni precedenti non riescono più a leggerlo.
